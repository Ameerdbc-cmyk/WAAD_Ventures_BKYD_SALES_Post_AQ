# WAAD_Ventures_BKYD_SALES_Post_AQ
End-to-end analysis of post-acquisition restaurant sales (Mar–Apr), including data cleaning and consolidation in Excel, validation of POS data in SQL, and development of a Tableau dashboard to identify performance trends, revenue concentration, and menu optimization opportunities.
